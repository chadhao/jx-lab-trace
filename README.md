# jx-lab-trace · 实验检测数据追踪系统

湖南江熙新材 · 岳阳城陵矶磨粉项目 —— **原料收货 → 生产中间样 → 成品** 全流程检测数据追踪。

## 一句话定位

给每一车原料、每一个吨袋、每一个样品发一张「身份证」，扫码贯穿始终；让「这批成品用了谁的料、当时测出来多少」随时答得出来。

## 核心特征

- **受托加工**为主（客户来料、客户提走），预留自购模式
- **吨袋是操作最小单位**：收货、投料、取样都落到袋
- **多对多谱系**：一车可拆多批、多车可并入一批
- **数据不可变**：只追加、不改行；修正＝作废＋新增
- **码携带身份、关系存库**：26 位定长结构化码（含版本位＋校验位）
- **报表层与业务层解耦**
